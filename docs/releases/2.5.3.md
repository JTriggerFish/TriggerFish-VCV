# TriggerFish Elements 2.5.3

## macOS compatibility fix

- Restored the Prog Sequencer parser's compatibility with VCV Rack's macOS
  10.9 deployment target. The macOS 12.3 SDK used by the VCV Library marks
  `std::any` as requiring macOS 10.13, so cpp-peglib now uses its header-only
  compatibility implementation on older deployment targets.
- Added regression builds for both parser value-storage implementations.

## Build coverage

- CI now covers all four VCV Library build targets: Linux x64 and Windows x64
  with VCV-derived cross-toolchains, and macOS x64 and arm64 with their Rack
  SDKs.
- The cross-toolchain and all Rack SDK builds are pinned to Rack 2.6.6.

TriggerFish Elements 2.5.3 targets VCV Rack 2 and retains all module slugs,
parameter IDs, and patch compatibility from 2.5.2. There are no DSP or UI
changes in this release.
