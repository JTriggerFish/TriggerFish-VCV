# TriggerFish Elements 2.5.1

## Prog Sequencer transport fix

- Ctrl+Space is now an immediate local event mute rather than a private score
  pause. Gate, Trigger, and Accent fall silent while the score, lane cursors,
  slides, random state, CV envelopes, and graphical beat position continue to
  follow the shared clock.
- Pressing Ctrl+Space while muted queues re-entry on the next musical quarter
  beat. Re-entry now uses the same receiver pulse phase that schedules notes,
  eliminating early chord hits caused by a separately acquired 24-PPQN grid
  after reset, patch startup, or multithreaded processing.
- Muted and queued-unmute states have persistent red and amber status-strip
  indications. A connected low RUN signal remains a distinct genuine score
  pause, while RESET and local restart retain their documented behavior.
- Trigger pulses continue to elapse behind the mute, preventing stale triggers
  from leaking when playback becomes audible again.
- Added behavioral regression coverage using the release smoke patch's compiled
  chord gesture. It verifies cursor and score advancement, event-output muting,
  trigger draining, and phase-accurate chord re-entry together.
