# TriggerFish Elements 2.5.6

- Fixed zipper noise from abrupt Resonance parameter updates in 303 Voice Core,
  including host automation and parameter mapping. The knob now uses short,
  sample-rate-independent smoothing; resonance CV retains audio-rate response.
- Clarified the 303 Voice Core manual's output routing and volume controls:
  `LP OUT` is filter-only, while `VCA OUT` includes the internal volume envelope
  or external VCA CV. The guide also explains gate length, decay/sustain,
  release timing, and the VCA CV amount control.

Existing module slugs, parameter IDs, and patch format are unchanged.
