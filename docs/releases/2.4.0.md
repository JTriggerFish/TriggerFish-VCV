# TriggerFish Elements 2.4.0

## New modules

- Added Room Reverb, combining positioned geometric early reflections with a
  fixed-vector stereo velvet-feedback late field and optional shimmer.
- Added Prog Sequencer, with a textual pattern language, polyphonic chord
  output, Notes-pass-synchronized control lanes, and an allocation-free
  playback display.

## DSP and development

- Standardized Windows development and Python extension builds on the MinGW
  toolchain used by the Rack SDK.
