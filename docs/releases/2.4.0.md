# TriggerFish Elements 2.4.0

## New modules

- Added Room Reverb, combining geometric early reflections with a
  position-dependent, stereo velvet-feedback late field and optional shimmer.
- Added Prog Sequencer, with a textual pattern language, polyphonic chord
  output, independently advancing lanes, and an allocation-free playback
  display.

## DSP and development

- Expanded the differentiable Room Reverb reference and its direct numerical
  parity coverage against the production C++ loop.
- Standardized Windows development and Python extension builds on the MinGW
  toolchain used by the Rack SDK.
