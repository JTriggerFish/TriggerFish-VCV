# TriggerFish Elements 2.5.4

## macOS compatibility fix

- Replaced the Prog Sequencer parser's `std::visit` calls with allocation-free
  `std::get_if` dispatch. The libc++ supplied with VCV's macOS 12.3 SDK marks
  variant visitation as requiring macOS 10.13, while Rack plugins target
  macOS 10.9.
- Added a source compatibility check for C++17 libc++ entry points known to be
  unavailable at Rack's macOS deployment target.

TriggerFish Elements 2.5.4 targets VCV Rack 2 and retains all module slugs,
parameter IDs, DSP behaviour, and patch compatibility from 2.5.3. There are no
UI changes in this release.
