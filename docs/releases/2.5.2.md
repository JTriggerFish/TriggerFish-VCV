# TriggerFish Elements 2.5.2

## Safety and static-analysis fixes

- Made empty Prog Sequencer runtimes safely return silence instead of
  dereferencing a missing compiled program, with regression coverage for both
  initial and explicitly cleared runtime states.
- Made Room Reverb scene construction structurally non-throwing on the audio
  thread. Checked public geometry, source, and material constructors retain
  their validation, while the realtime path uses the same calculations with
  controls sanitized before construction.
- Hardened Prog Sequencer state transfer and the Room Reverb plan tooltip
  against null internal pointers.
- Rewrote a handful of equivalent parser, chord compiler, and Electric Piano
  expressions so VCV's C++11-configured cppcheck pass can analyze the C++17
  plugin sources without false diagnostics.
- Added regression coverage for non-finite Room Reverb controls and
  unconfigured Prog Sequencer playback.

## Compatibility and license

TriggerFish Elements 2.5.2 targets VCV Rack 2 and retains all module slugs,
parameter IDs, and patch compatibility from 2.5.1. Normal Room Reverb geometry
and material calculations are numerically unchanged. Prog Sequencer remains in
beta.
