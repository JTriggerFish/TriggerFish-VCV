# TriggerFish Elements 2.5.0

Version 2.5.0 is under development. Release notes will be compiled as the
development cycle progresses.

## Prog Sequencer

- Added semantic Jazz-chord factor overrides, `basic`, `rootless_3notes`, and
  `rootless_4notes` recipes, and deterministic contextual voice leading.
  Altered dominants choose separate b9/#9 candidates, extended chords preserve
  useful voice counts by omitting fifths/roots, and `key` records an explicit
  transposition anchor without imposing a scale on chord roots.
- Added named reusable `rhythm` gestures. `notes` and `chords` can now act as
  a held musical-time pitch timeline sampled by those gestures, while either
  spelling still supports direct event sequencing. Target `>pitch` and gesture
  `>x` slides compose with the separated form, and semicolons remain
  whitespace-only visual separators.
- Live evaluation now distinguishes next-quarter and next-scheduler-step
  activation. Compatible edits preserve phase; direct/gesture representation
  changes restart only the current arrangement term on the next quarter beat.
  Program publication is hazard-protected so rapid UI replacements cannot
  invalidate a candidate currently inspected by the audio thread.
- `chords` now interprets bare named roots as standard major triads,
  `transpose_key KEY` uses the sequence's written `key`, and reduced voicings
  preserve defining upper extensions such as the eleventh in `Dm11`.
- Names which are complete inline rhythm patterns are reserved, preventing a
  reusable rhythm such as `x` from being silently interpreted as inline syntax.
- Grouped editor width and heatmap choices into a compact nested context menu.
- Added Acid bassline, Slow bassline, and Descending arpeggio programs to an
  Examples submenu. Loading an example creates a Rack undo entry and waits for
  explicit evaluation.
