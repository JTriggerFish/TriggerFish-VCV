# TriggerFish Elements 2.5.0

## Electric Piano

This release adds a sample-free, sixteen-voice electric piano loosely inspired
by a Rhodes Mk1 and its Peterson-era Suitcase electronics.

- A finite-mass hammer excites a calibrated tine/tone-bar system through a
  Hunt-Crossley contact law. Coupled body coordinates and seven short attack
  coordinates produce velocity- and register-dependent body, bark, bell, and
  decay without samples or a prescribed brightness envelope.
- A two-dimensional nonlinear magnetic-pickup model derives the harmonic ladder
  and intermodulation from tine motion. Strike, Hammer, Tone, Proximity, Bell,
  Body, Coupling, Decay, and Release expose physically meaningful adjustments
  around calibrated defaults.
- Sixteen pickup voices feed one shared nonlinear amplifier. Its preamplifier,
  active Bass/Treble feedback network, germanium power stages, recovering
  supply, transformer drive, and provisional reactive speaker load are modelled
  as stateful circuit sections rather than a static clipping curve. Drive is
  level-compensated at the circuit volume node; Output remains a separate final
  level control.
- Polyphonic retrigger handling preserves released-note tails when MIDI channels
  are reassigned. An explicit Pedal input, differentiated key/damper mechanics,
  velocity curve, and full-range dynamics support expressive keyboard playing.
- The Suitcase path includes stereo vibrato. One bipolar modulation input offers
  exponential FM, linear through-zero FM, or phase modulation with mono
  broadcast and polyphonic addressing.
- Collision integration, nonlinear pickup reconstruction, and the amplifier use
  targeted multirate paths. High-mode tapering and reconstruction filters limit
  aliasing, while control-rate coefficient updates, shared immutable tables, and
  inactive-path bypasses keep polyphonic CPU use practical.
- The accompanying modelling notes record topology, physical quantities,
  calibration choices, known data gaps, reference measurements, regression
  renders, and performance measurements.

## Prog Sequencer and Transport

- Added named reusable `rhythm` gestures. `notes` and `chords` can now provide a
  held musical-time pitch timeline sampled by a gesture, while either spelling
  still supports direct event sequencing. Slides compose with the separated
  form, and semicolons remain whitespace-only visual separators.
- Added standard named jazz chords, explicit chord-tone overrides, `basic`,
  `rootless_3notes`, and `rootless_4notes` recipes, and deterministic contextual
  voice leading. Altered dominants choose separate b9/#9 candidates; extended
  chords preserve defining upper extensions while omitting roots or fifths when
  appropriate.
- Chord sequences use explicit note roots. A written `key` is a transposition
  anchor rather than a scale constraint, and `transpose_key KEY` provides a
  well-defined whole-progression transposition.
- Live evaluation now distinguishes next-quarter and next-scheduler-step
  activation. Compatible edits preserve phase; incompatible representation
  changes restart the current sequence term on the next quarter beat.
- Program publication is hazard-protected against rapid UI replacements.
  Startup and shared Transport reset/run synchronization were tightened for
  multithreaded Rack operation and audio-device changes.
- Added Acid bassline, Slow bassline, and Descending arpeggio programs to the
  Examples menu. Slow bassline is the new-module default. Loading an example is
  undoable and waits for explicit evaluation.
- Refined the editor context menus, status reporting, documentation, grammar,
  shortcuts, and regression coverage.

## Event Merge 2

- Added Event Merge 2, an 8 HP utility that concatenates two aligned polyphonic
  Pitch/Gate/Trigger/Velocity/Accent bundles without summing pitch voltages.
- Up to sixteen performance-event voices are retained in input order. Missing
  companion channels use safe event defaults, making the module suitable for
  combining a sequenced chord performance with a live MIDI keyboard.

## DSP and performance

- Reduced hot-path work in the 4072 filter/4019 VCA voice, Unison Oscillator,
  Wavefold Oscillator, Room Reverb, shimmer pitch shifter, and Electric Piano.
  Expensive control conversions and coefficient changes are cached or moved to
  control rate where their audio-rate evaluation was numerically redundant.
- Removed residual automatic-differentiation solvers from the amplifier path and
  replaced them with explicit compact Jacobians, retaining the circuit equations
  while reducing CPU and build complexity.
- Added focused benchmarks for the 4072 voice, wavefolder, Room Reverb,
  Peterson amplifier, and Electric Piano, together with expanded numerical,
  spectral, aliasing, gain-staging, polyphony, and concurrency regressions.
- Fixed a platform-dependent integer type mismatch in the contextual voicing
  score so the native tests and plugin build compile consistently on Linux,
  Windows/MinGW, and macOS.

## Patches, panels, and documentation

- Expanded the musical Room Reverb smoke patch to three synchronized sequences:
  bass, folded arpeggio, and syncopated three-note electric-piano voicings. Live
  keyboard events merge with the piano sequence, sustain uses MIDI CC64, and the
  stereo room output feeds Audio, Scope, and a 48 kHz/24-bit Recorder.
- Added compact panels and rendered documentation previews for Electric Piano
  and Event Merge 2, and replaced the dense Prog Sequencer preview with its
  readable Slow bassline example.
- Improved smoke-patch refresh behavior so disconnected local MIDI/audio state
  cannot overwrite a valid selected-device configuration.

## Compatibility and license

TriggerFish Elements 2.5.0 targets VCV Rack 2. Existing module slugs and
parameter IDs are retained. Electric Piano and Event Merge 2 are new module
slugs. Prog Sequencer remains in beta; this release deliberately extends and
clarifies its language semantics, so programs relying on undocumented chord
interpretation should be reviewed against the updated reference.
