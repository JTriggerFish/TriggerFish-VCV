# TriggerFish Elements 2.2.0

This release adds 303 inspired modules for building acid-style voices and
substantially revises the DSP, documentation, and development workflow of the
existing collection.

## New modules

### 303 Oscillator

- Circuit-informed saw oscillator and transistor square-wave shaper.
- Continuous saw-to-square morphing with voltage control.
- TB-303-style gated pitch slide with voltage-controlled slide time.
- Exponential and linear through-zero FM.
- Fractionally timed, minBLEP-corrected hard sync.
- Up to 16 polyphonic voices with independent oscillator and resampling state.
- 4x oversampling by default, with a lower-CPU 2x mode.

### 303 Voice Core

- Nonlinear four-stage diode ladder with the TB-303 coupling and resonance
  networks.
- Internal filter and volume envelopes, accent processing, and a BA662-style OTA
  VCA.
- Stock and extended resonance ranges, continuous bass extension, cutoff FM,
  resonance CV, and external VCA control.
- Stock and Devil Fish-inspired articulation options.
- Up to 16 polyphonic voices with independent filter, envelope, accent, and VCA
  state.
- 4x oversampling by default, with a lower-CPU 2x mode.

## Existing modules

- VDPO receives a structure-aware, prewarped integrator with improved pitch
  tracking, numerical stability, and performance.
- Slop and Slop 4 use a more stable linear-drift conversion and Rack's standard
  pitch approximation. Shared and common drift defaults are reduced to 5%.
- VCA renames Gain to Drive, extends its useful saturation range, and defaults
  both CV input amounts to 100%.
- Numerical edge cases, output limiting, state reset, and sample-rate handling
  have been hardened across the DSP models.

## Documentation and development

- New module guides, technical reports, panel renders, and playable smoke-test
  patches.
- Reproducible native and Python DSP tests and quality/performance benchmarks.
- Current Windows and Linux development instructions using the Rack 2.6.6 SDK,
  CMake, uv, and pre-commit checks.
- Updated Eigen dependency, packaged outside Rack's generated dependency tree,
  and removal of obsolete Visual Studio project files.

## Compatibility

TriggerFish Elements 2.2.0 targets VCV Rack 2. Existing patches using Slop,
Slop 4, VDPO, and VCA retain their module slugs and parameter ordering. The two
303 modules are new in this release.
