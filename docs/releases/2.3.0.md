# TriggerFish Elements 2.3.0

## 4072 Voice Core

This release adds 4072 Voice Core, a polyphonic ARP-inspired filter, envelope,
and amplifier module built around three reusable DSP models.

- A circuit-scaled ARP 4072 four-pole low-pass model retains the unequal audio
  and resonance-return scaling of the input differential pair and the locally
  fed-back nonlinear filter stages.
- The cutoff control extends to 20 kHz using ARP's published correction for
  the original 4072 high-frequency limitation.
- An ARP 4019-style VCA provides linear and 10 dB/V exponential control paths,
  an initial-gain control, and a separate audio input which overrides the
  normalled filter output.
- Two independent 0–10 V envelopes can each operate as AR, AD, or ADSR. Their
  outputs are available for external patching. Independent filter and VCA
  modulation inputs can add to or replace the corresponding internal envelope
  and switch between linear and exponential control laws.
- The shared Curve control spans near-linear to tight exponential timing, with
  its default calibrated to the original 4020 ADSR and board-4 AR circuits.
- Blue slider illumination follows the active envelope segment and level.
- Every voice has independent filter, envelope, and VCA state. The complete
  nonlinear filter-to-VCA path uses 4x oversampling by default, with a 2x mode
  available for larger patches.

## DSP and development

- Added independent small-signal references, circuit-ratio checks, nonlinear
  stress tests, and combined filter/VCA tests for the new models.
- Corrected the loaded 4072 stage resistance and complete 4019 input divider,
  and added continuous-time filter, VCA, and envelope comparisons.
- Added bounded recovery for an unconverged filter solve and consistent output
  safety after decimation on both the filter and normalled VCA paths.
- Reconstructed audio-rate pitch, filter FM, resonance, waveform, damping, and
  VCA controls inside the corresponding 2x/4x paths before nonlinear mapping.
- Added an offline panel renderer for the new envelope sliders and their lights.
- Added a MIDI-playable 4072 Voice Core smoke patch and refreshed module,
  panel, patch, and public-repository checks.

## Compatibility

TriggerFish Elements 2.3.0 targets VCV Rack 2. Existing module slugs and patch
formats are unchanged. 4072 Voice Core is new in this release.
