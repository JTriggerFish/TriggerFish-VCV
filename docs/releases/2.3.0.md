# TriggerFish Elements 2.3.0

## 4072 Voice Core

This release adds 4072 Voice Core, a polyphonic circuit-modelled ARP filter, dual
envelope, and amplifier module.

- The circuit-modelled ARP 4072 four-pole low-pass retains the original
  filter's drive, resonance behaviour, and high-frequency character.
- The cutoff control extends to 20 kHz using ARP's published correction for
  the original 4072 high-frequency limitation.
- An ARP 4019-style VCA provides linear and 10 dB/V exponential control paths,
  an initial-gain control, and a separate audio input which overrides the
  normalled filter output.
- Two independent 0–10 V envelopes can each operate as AR, AD, or ADSR. Their
  outputs are available for external patching. The amplifier envelope can use
  the VCA's linear or exponential control law in every mode. Independent filter
  and VCA modulation inputs can add to or replace the corresponding internal
  envelope and select their own linear or exponential laws.
- The initial patch uses fast AD contours and the VCA's exponential response as
  a playable plucked-instrument starting point.
- The shared Curve control spans near-linear to tight exponential timing, with
  its default calibrated to the original 4020 ADSR and board-4 AR circuits.
- Blue slider illumination follows the active envelope segment and level.
- Every voice has independent filter, envelope, and VCA state. The complete
  nonlinear filter-to-VCA path uses 4x oversampling by default, with a 2x mode
  available for larger patches.

## Wavefold Oscillator

- Added a polyphonic sine/triangle oscillator with Hinge, Lockhart, and Serge
  folder characters, exponential or through-zero FM, and separate oscillator
  and folded outputs.
- Added one to four true-unison voices with pitch spread, plus independent
  Alive drift for waveform, fold, and symmetry over a 0.5–120 s time range.
- External audio can replace the internal oscillator at the folder input. The
  nonlinear path uses 4x oversampling by default with a 2x lower-CPU mode.

## Unison Oscillator

- Added a polyphonic one-to-sixteen-voice saw/pulse stack with smooth voice
  transitions, normalized mono output, equal-power stereo width, and up to
  50 cents of spread.
- Added internal or external PWM, centre or stacked sub-oscillator modes, and
  bipolar CV control of spread and width.
- Added integrated Slop controls for common hum and drift, individual drift in
  cents or hertz, and per-voice pitch-tracking variation.

## Existing module improvements

- 303 Oscillator now uses a more detailed circuit model of the original Q8
  square-wave shaper. It reproduces the pitch-dependent pulse width, asymmetric
  edges, and saturation more closely while keeping the extended oscillator range useful.
  The saw-to-square morph remains phase-aligned and maintains a consistent
  level through its midpoint.
- Audio-rate pitch, filter FM, resonance, waveform, damping, and VCA modulation
  are smoother at high frequencies, with lower aliasing in the affected
  oversampled modules.
- Oversampled outputs now approach Rack's voltage limits smoothly. Extreme
  drive and modulation settings recover cleanly while preserving rounded peaks.

## Compatibility

TriggerFish Elements 2.3.0 targets VCV Rack 2. Existing module slugs and patch
formats remain compatible. 4072 Voice Core, Wavefold Oscillator, and Unison
Oscillator are new in this release.

Existing patches load directly in 2.3. Patches using 303 Oscillator will use the
revised square-wave shaper and can sound different toward the square end of the
**Wave** control, especially at extreme **Shape** settings.
