# TriggerFish Elements 2.3.1

## 303 Voice Core

- Corrected the Devil Fish Bass model to follow the C20/C21 differential
  coupling network. The control now moves its first-order corner from about
  92 Hz toward 9.2 Hz instead of applying two cascaded post-filter shelves.
- Reduced excessive low-frequency gain and overload when Bass, high resonance,
  and audio-rate cutoff FM are combined.
- Added regression coverage for the high-resonance, 100 Hz cutoff-FM case and
  documented the available output headroom at extreme Bass settings.

## 303 Oscillator and test patch

- Cleaned up the Octave control markings and refreshed the module image in the
  manual.
- Expanded the playable 303 test patch with the complete Gibber Acid motif and
  its i, -iv, and -V song transpositions, plus independent cutoff, resonance,
  and optional linear-FM modulation.

## Development workflow

- The Windows launcher now prefers Rack Pro when it is installed, while still
  supporting Rack Free and an explicit `RACK_EXECUTABLE` override.

## Compatibility

TriggerFish Elements 2.3.1 targets VCV Rack 2 and keeps all module slugs and
patch formats from 2.3.0. Existing patches load directly; patches using strong
Bass extension can sound less overdriven because of the corrected coupling
response.
