# TriggerFish Elements 2.5.5

## Prog Sequencer fixes

- Fixed scale degrees and Roman chord roots ignoring `key`. For example,
  `key D`, `scale dorian`, and `chords i` now produce D F A, rather than C Eb G
  ([#13](https://github.com/JTriggerFish/TriggerFish-VCV/issues/13)). An explicit
  `tonic` takes precedence regardless of setting order; named chord roots keep
  their written meaning.
- Fixed repeating chord progressions climbing or descending out of their
  written register ([#12](https://github.com/JTriggerFish/TriggerFish-VCV/issues/12)).
  Automatic inversions now stay within a fixed register window while retaining
  smooth voice leading. Octave suffixes, relative register marks, Octave lanes,
  and transposition move that window. Explicit parenthesized pitch voicings
  continue to specify exact notes.
- Removed temporary heap allocations from rootless voicing selection.

## Other changes since 2.5.4

- Optimized Electric Piano and Room Reverb DSP processing.
- Hardened shared DSP handling of non-finite and denormal audio values.

This release targets VCV Rack 2 and retains existing module slugs, parameter
IDs, and patch format. Patches using automatic chord voicing can sound different
because register drift is corrected. Patches with a non-C `key`, scale degrees
or Roman chords, and no explicit `tonic` now use that key as their tonal centre;
write `tonic C@4` to retain the old C-rooted interpretation.
